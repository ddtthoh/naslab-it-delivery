比线上多出来的地方

  • 密码有显/隐钮 —— 现在线上打错了只能全删重打
  • 注册和重设密码有强度条(只提示,不拦提交;门槛仍是线上的 6 位)
  • 报错在字段下方就地显示,不再是顶部一条笼统的红字
  • 忘记密码提交后切成独立的「已寄出」屏,文案不透露邮箱是否存在(后端也请照做)
  • 901px 断点:桌面左图右表单,手机左幕收起、表单占满 —— 和官网同一个断点
  • ar / fa 的 RTL 规则已经写好,<html dir="rtl"> 即可
  • 每个输入框都有真 <label for>,报错是 role="alert",焦点环 2px 金色

交给 IT 要说的三句话

1. 纯静态,没有构建步骤 —— 解压就能开,四个 HTML + 一个 CSS + 一个 JS。

2. 表单现在一律拦截提交。assets/auth.js 里标了 [接线] 的那段 preventDefault 删掉即可正常 POST。

3. assets/img/captcha-sample.svg 是画出来的占位图,上线必须换成后端出图的地址(data-src="/captcha" 已经标好位置)。
